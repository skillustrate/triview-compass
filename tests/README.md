# Runtime tests

Keep deterministic implementation tests separate from model-quality evaluations in `evals/`.

- Unit tests cover snapshot capture, path and secret policies, budgets, report schemas, evidence anchors, and deterministic consolidation.
- Sandbox preflight and runner tests cover rootless local engine and pinned-image checks, bounded Podman arguments, sanitized snapshot materialization, output scanning, startup/timeout/output failures, and no host fallback. A separate synthetic real-container probe checks effective mount, network, user, and cgroup behavior; its result depends on the installed rootless Podman profile and an already-local pinned Python image.
- Workflow and CLI tests cover explicit execution opt-in and disclosure, structured sandbox reports, incomplete verdicts, metadata-only audits, missing-runtime guidance, and malformed adapter-result refusal. `evals/scripts/probe-sandbox-workflow.js` exercises the CLI and report/audit path with actual Podman execution and diagnostic reviewers that make no provider calls.
- Security tests will verify deny behavior and fail-closed paths; they must not rely on an LLM judge.

`preflight.test.js` covers explicit-file redaction, sensitive paths, traversal and duplicate paths, file/line/byte budgets, scanner failure and timeout, rename handling, snapshot identity, and bundle immutability. `git-preflight.test.js` creates synthetic repositories inside the test container to check committed-content capture, ancestry refusal, symlinks, sensitive renames, binary reporting, byte limits, and timeout. `contract-preflight.test.js` checks schema, provider, capability, and conservative token-bound refusal. `adapter-handshake.test.js` checks runtime capability refusal, provider identity, exact serialized payload counting, and adapter error privacy using local fakes. `model-routing.test.js` checks mixed routes, mismatch refusal, report attribution, and routed audit privacy. `claude-code.test.js` checks tool-free sessions and selected account profiles/models with mocked processes. `prompt-builder.test.js` checks role/skill routing, opaque file IDs, excluded-path privacy, content hashes, and full-prompt handshake budgeting. `review-dispatch.test.js` checks role isolation, identity and evidence validation, disagreement retention, incomplete and partial reporting, unsafe output refusal, and timeout. `static-review-harness.test.js` checks frozen scope binding and changed-scope refusal; `static-review.test.js` checks end-to-end wiring with fake agents and refusal before invocation. `lm-studio.test.js` uses mocked SDK and HTTP responses to check the exact stateless request, local loaded model, bounds, and unsafe response refusal. `secret-scanning.test.js` measures isolated patterns and contextual fixtures, including false alerts and known gaps. `audit.test.js` checks canonical policy hashing and metadata-only output. `audit-store.test.js` checks private file mode, content privacy, expiry, and disabled retention. Run deterministic `npm test` inside Podman. Live agent calls run locally.

Phase 5 tests verify preflight-only causes no reviewer calls, execution, or audit writes, preflight is delivered before dispatch, unsupported isolation and invalid retention are refused, custom harnesses can be supplied, and readable reports retain validation gaps while escaping terminal controls. Live Claude checks use synthetic input on the host; deterministic tests stay in Podman.
