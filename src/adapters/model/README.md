# Model adapter implementations

Implementations in this directory translate provider-neutral reviewer requests to model APIs. They must respect configured data policy and budgets, identify the provider/model used, validate responses, and never switch providers silently.

Before dispatch, implementations provide the capability and exact-payload methods in [the adapter handshake contract](../../../adapters/README.md#pre-dispatch-handshake). `prepareRequest` and `countInputTokens` perform local preparation only. The dispatcher sends the counted payload unchanged and rejects a provider or runtime-setting change.

`claude-code.js` is the provisional subscription adapter. It launches a separate tool-free, nonpersistent Claude Code process for each role with structured output and a fixed hosted-provider identity. An explicit `configDir` selects a Claude account profile, and `adapterId` names that profile in reports. A source-free auth check requires a signed-in first-party subscription before prompt preparation. Its token bound uses UTF-8 bytes plus a large protocol reserve because the CLI has no preflight tokenizer. Mocked container tests and live local synthetic reviews pass, including two-model routed reviews; exact model identity and context limits remain unverified. `lm-studio.js` is the local model adapter used for synthetic diagnostics.

The v1 subscription profile is qualified for CLI 2.1.300 and refuses unreviewed versions before prompts. Safe/restricted flags and source-bounded response IDs, line limits, and skill enums are used alongside local validation. The inherited provider/model/trace environment is cleared, authentication and version checks are bounded, and reported usage is checked against invocation budgets when present. Optional `onMetrics` receives only role/invocation metadata, numeric reported usage/API-equivalent estimates, and observed model IDs; it receives no source or transcript. Exact alias identity and context assumptions remain exposed. The experimental local adapter rejects public endpoints and redirects; a private server is still a trusted data-handling boundary.
